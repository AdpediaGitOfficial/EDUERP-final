# Agent notes

Greenwood School ERP — a TanStack Start frontend on a self-hosted NestJS + Prisma API.

- Package manager: **bun** (`bun install`, `bun run dev|build|lint|typecheck`). Commit `bun.lock`.
- Design tokens are locked in `DESIGN_SYSTEM.md`; do not change colors, fonts, radii, or
  component styling without explicit approval. All tokens live in `src/styles.css`
  (Tailwind v4 CSS-first config — there is no `tailwind.config.ts`).
- `src/routeTree.gen.ts` is generated by the TanStack Router plugin — never edit by hand.
- **Backend**: the app is 100% off Supabase (migration complete — see
  `BACKEND_MIGRATION_LOG.md`). The frontend reaches the backend only through
  `src/lib/api/client.ts` (`apiGet`/`apiPost`/`apiFetch`, JWT session); there is no Supabase or
  direct-DB client in the frontend. The API lives in `api/` (NestJS + Prisma); RLS policies are
  reproduced there as guards + service-layer scoping. New reads/writes go through an API endpoint,
  never a client-side DB call.
- Demo accounts (`admin|teacher|parent|student@greenwood.test`, password `Greenwood@2026`) and
  their identity chain are regression-critical; never reseed or mutate them casually.
