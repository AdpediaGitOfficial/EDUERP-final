# Agent notes

Greenwood School ERP — standalone TanStack Start + Supabase application.

- Package manager: **bun** (`bun install`, `bun run dev|build|lint|typecheck`). Commit `bun.lock`.
- Design tokens are locked in `DESIGN_SYSTEM.md`; do not change colors, fonts, radii, or
  component styling without explicit approval. All tokens live in `src/styles.css`
  (Tailwind v4 CSS-first config — there is no `tailwind.config.ts`).
- `src/routeTree.gen.ts` is generated by the TanStack Router plugin — never edit by hand.
- Supabase: browser client `src/integrations/supabase/client.ts`; service-role client
  (`client.server.ts`) must only be imported from server-side code.
- Demo accounts (`teacher@greenwood.test`, `parent@greenwood.test`, `student@greenwood.test`)
  and their identity chain are regression-critical; never reseed or mutate them casually.
